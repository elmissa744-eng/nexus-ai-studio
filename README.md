## ✨ Características

| Herramienta | Descripción |
|-------------|-------------|
| **💬 Chat IA** | Asistente conversacional con respuestas contextuales |
| **🖼️ Generador de Imágenes** | Generación real de imágenes con [Pollinations.ai](https://pollinations.ai) (gratis, sin API key) |
| **✍️ Herramientas de Texto** | Mejorar prompts, reescribir, resumir, expandir y traducir |
| **📚 Biblioteca de Prompts** | 12 prompts listos para copiar y usar |

## 🖥️ Captura de pantalla / Estilo

Diseño **dark mode** con acentos neón (púrpura + cian), glassmorphism suave y experiencia responsive.

## 🛠️ Tecnologías

- HTML5 + CSS3 (variables CSS, animaciones, responsive)
- JavaScript vanilla (sin frameworks)
- Pollinations.ai para generación de imágenes
- Google Fonts (Inter + JetBrains Mono)

## 📂 Cómo usarlo localmente

1. Descarga o clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡Listo! (el generador de imágenes necesita conexión a internet)

```bash
git clone https://github.com/elmissa744-eng/nexus-ai-studio.git
cd nexus-ai-studio
# Abre index.html con tu navegador
```

## 📋 Notas técnicas

- **Chat y herramientas de texto**: lógica local / demo (fácil de conectar a OpenAI, Grok, Claude, etc.)
- **Generador de imágenes**: integración real y gratuita
- Todo en un solo archivo HTML para máxima portabilidad
