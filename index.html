Nexus AI Studio

Proyecto de portafolio que demuestra la integración de múltiples herramientas de inteligencia artificial en una interfaz moderna y unificada. Diseñado con un enfoque tech oscuro y experiencia de usuario fluida.

Funcionalidades incluidas:

  • Chat conversacional con respuestas contextuales
  • Generador de imágenes con Pollinations.ai (sin API key)
  • Herramientas de texto: mejorar prompts, reescribir, resumir, expandir y traducir
  • Biblioteca de prompts listos para usar

Este proyecto está pensado para mostrar habilidades de frontend, diseño de interfaces y conocimiento de herramientas de IA modernas. Ideal para incluir en un portafolio de desarrollador o diseñador.
